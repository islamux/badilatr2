سطح هجوم صغير بقدر السكون

الذين نحن بخير

  • لا خادم ← لا SQL injection، لا SSRF، لا كشف جلسة، لا API endpoints.

طبقات خارجية

  • .htaccess مع CSP صارم: default-src 'self'، script-src 'unsafe-inline' (Next inline chunks)، frame-ancestors 'none' (public/.htaccess).
  • رؤوس: X-Content-Type-Options, X-Frame-Options DENY, Referrer-Policy strict-origin-when-cross-origin.
  • Caching: woff2 immutable max-age=1y، HTML بلا تخزين، connect-src 'self' يمنع تسريب الطلبات الخارجية.

مقايضة الذيفان: 'unsafe-inline' للـ scripts شرط Next static (inline chunks) — مضبوطة المرض عبر ضيق default-src 'self' و stript no else.
