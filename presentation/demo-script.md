# سكربت العرض الحيّ — بديل عطر ٢

<div dir="rtl">

نص مرقّم للعرض الحيّ (11 دقيقة من ميزانية الستين، مع خطة ضغط إلى 5). الهدف في كل خطوة: **إثبات السلوك من الخارج، ثم ربطه إلى ملف/سطر من الداخل** — لا تَروِ القصة قبل تشغيلها.

> الأرقام اللاتينية هنا للفهارس وأسماء الملفات فقط؛ الأرقام الظاهرة للمستخدم عربية-هندية عبر `arN()`.

## 0) الاستعداد القبلي (قبل الصعود بمدة)

```bash
pnpm install          # تثبيت الاعتمادات
pnpm typecheck && pnpm lint && pnpm build
npx serve out -l 3001 # أو: python3 -m http.server 3001 -d out
```

- افتح `http://localhost:3001/` و `http://localhost:3001/quiz/` سلفاً.
- افتح DevTools في نافذة منفصلة: Network + Console فارغة.
- جهّز التبويب بحالة فلترة مفيدة (مثال: بحث «عود» + عائلة خشبية) لنسخ رابطها لاحقاً.
- **البديل عن serve**: إذا تعذّر `npx serve`، استخدم `python3 -m http.server 3001 -d out`، أو افتح `out/index.html` مباشرة (يعمل معظم التفاعل، لكن شريحة الـ 404 تُثبت عبر الخادم فقط).

## الخطوات المرقّمة

### 1) إثبات السكون — لا خادم في زمن التشغيل (≈1.5 دقيقة)

**افتح القشرة:**
```bash
ls out/                 # index.html + quiz/index.html + 404.html + _next/...
```

**قل:** «هذا كل الناتج — ثنائيات جاهزة لأي استضافة ثابتة. ثلاث صفحات ساكنة».

**في المتصفح:** افتح `http://localhost:3001/` ثم Ctrl+Shift+P → «Disable JavaScript» → إعادة تحميل:

- كامل الفهرس يُعرض (البطاقات، الأقسام، الأرقام) قبل أي JS.
- الفلترة لا تعمل دون JS (متوقّع) — لكن الترويسة والأقسام حقيقية.

**من الداخل:** `<html lang="ar" dir="rtl">` في `src/app/layout.tsx:29`، والتصدير مجبور في `next.config.ts:4`.

**قل:** «العمود الفقري ساكن؛ ما لا نجده في البناء يستبعد صراحةً».

### 2) البحث والتطبيع العربي (≈1.5 دقيقة)

**في المتصفح:** في خانة البحث اكتب:

- «عود» ⇄ «عُود» ⇄ «عود» (مع تشكيل/بدونه) — النتائج متطابقة.
- «فانيليا» — تطابق عبر النوتات وليس الأسماء فقط.
- «لطافة» — مطابقة على اسم الدار العربية (البديل).
- `Creed` — مطابقة لاتينية.

**من الداخل:** التطبيع في `src/lib/arabic.ts:14-21` (`norm`)، والحقول المبحوثة في `buildHaystacks` (`src/lib/catalog/filter.ts:6-14`).

**قل:** «substring مطبَّع على حصيدة مجمّعة — بلا regex وبلا فهارس خارجية».

### 3) مشاركة الحالة عبر الرابط (≈1.0 دقيقة)

**في المتصفح:** فعّل «آمن فقط للشراء الأعمى»، اختر عائلة «خشبية»، ترتيب «الأعلى تقييماً». انسخ الرابط، افتحه في تبويب جديد:

- الحالة تُسترجع كاملة + العدّاد «يعرض X من 569».
- حرّر الرابط يدوياً: `&cat=xyz` غير صالح ← يتجاهل ويبقى على الوضع الحالي.

**من الداخل:** الحفظ `saveHash` في `src/lib/catalog/state.ts:31-54`، والتحقق `applyHash` في `state.ts:57-72`، واستعادة عند المونت في `useCatalogState.ts:34-38`.

**قل:** «الرابط مصدر حالة موثوق لكنه مثبت: المدخلات غير الصالحة تُرفض صمتاً — لا نقرة ولا أخطاء».

### 4) المفضلة وإعادة التحميل (≈1.0 دقيقة)

**في المتصفح:** ♥ على بطاقة، F12 → Application → Local Storage → `http://localhost:3001`:
- المفتاح `p100favs` يحتوي مصفوفة فهارس، مثال `[0,7]`.

أعد التحميل: المفضلة باقية، وزر «♥ المفضلة» يعرض العدد. الآن أمسح `p100favs` وأعد التحميل — لا انهيار.

**من الداخل:** `useFavorites.ts:4` (المفتاح)، `:20-24` (الاستعادة بعد المونت)، `:34-41` (الحارس `ready`).

**قل:** «الفهارس ليست أسماء — عقد مع النسخة القديمة؛ لذلك ترتيب السجلات ثابت».

### 5) Hydration — أقوى شريحة (≈2.0 دقيقة)

**أ) إثبات الفرق:** في Console بصفحة الفهرس، نفّذ:
```js
// المثال: أين يقرأ المشروع ساعة المتصفح؟
document.querySelector('.date')?.textContent;
```
التاريخ في الترويسة يُحسب في زمن البناء، وقد يختلف نصّه عن تاريخ الزائر ليلاً — لذا `<time suppressHydrationWarning>` في `src/app/page.tsx:348`. لاحظ أن Console خالية من تحذيرات `did not match`.

**ب) النمط الآمن (المستخدم فعلاً):** افتح `src/hooks/useFavorites.ts`:
1. `useState(new Set())` — القيمة الافتراضية مطابقة لرندر الخادم.
2. القراءة داخل `useEffect` بعد المونت — لا lazy initializer.
3. `if (!ready) return` قبل `localStorage.setItem` — حارس يمنع مسح القيم قبل الاستعادة.

**ج) النمط الخاطئ (خارج المشروع، للتوضيح فقط):**
```js
// ⚠ مثال تعليمي — لا يوجد في الكود
const [theme] = useState(() => localStorage.getItem('theme') ?? 'light');
```
الخادم صادَر «light»؛ أول رندر للعميل صادَر «dark» ← شجرتان مختلفتان قبل الالتزام ← تحذير/إعادة معالجة.

**قل (بشكل صارم):** «نحن لا ندّعي أنه بلا مشاكل؛ الفرق بين تاريخ البناء وتاريخ الزائر معترف به صراحة في الكود».

### 6) الاختبار: من الإجابات إلى البطاقة (≈1.5 دقيقة)

**في المتصفح:** `http://localhost:3001/quiz/` ← أجب 6 أسئلة (في Q2 و Q4 اختر أكثر من خيار) ← «اكتشف نتيجتي»:

- بصمة عطرية + قائمة 5 عطور بدرجات وأسباب.
- اضغط «شاهده» على الأول ← يقفز إلى `/#p-N` في الفهرس مع وميض.

**من الداخل:** التقييم الكامل لكل الـ 569 في حلقة بلا شبكة: `getResults` في `src/lib/quiz/scoring.ts:158-170`، والدرجة `scorePerfume:93-149`. القفز: `QuizClient.tsx:118-123` + استقبال `#p-` في `page.tsx:263-283`.

**قل:** «الحساب في نفس كتلة المنتج — `initCatalogData()` مشترك بين الصفحتين».

### 7) الجوال + الوصولية + 404 (≈1.5 دقيقة)

- **عرض هاتف (≤760px)**: زر «⚙ فلترة» يفتح اللوحة؛ اغلاقها بـ ✕ / «Esc» / النقر خارجها.
- **لوحة مفاتيح**: Tab عبر الترويسة يصل إلى «تخطَّ إلى المحتوى» (skip link).
- **Reduced motion**: DevTools → Rendering → «Emulate prefers-reduced-motion» — الحركات تُعدم (`globals.css:1640-1657`).
- **404**: افتح `http://localhost:3001/xyz` ← تُعرض صفحة ثابتة (ملف `out/404.html`).

## خطة الفشل والاحتياط

- **تعذّر الفلترة (JS مكسور):** أعد تحميل؛ إن استمر، اطلب الصفحة الثانية `quiz/` — إن تعطلت أيضاً، عد إلى سكربت الشاشة الثابتة (تقطيع شاشات في `presentation/backup-shots/` إن وُجد).
- **شبكة مقطوعة:** الخطوط تتدهور لأن favourite fallback من النظام؛ شرّح بدون شكوى.
- **تحذير Console من الاستضافة:** اذكر أن CSP/الرؤوس في `public/.htaccess` يُفعَّل نزع إمكانية الحمل — النسخة المحلية `serve` لا تحمل الرؤوس.
- **نفاد الوقت في البند 5:** اقسم الجزء «ج» من البند 5، وأكمل بعد العرض أو في قراءة qa-guide.md (سؤال عن mismatch).
