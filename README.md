# بديل عطر ٢ · أفضل العطور الرجالية وبدائلها

> دليل تفاعلي واحد يضم نخبة العطور الرجالية الأعلى تقييماً، إلى جانب **البديل العربي/الاقتصادي** الموثوق لكل قارورة — مع النوتات العطرية، نسب الثبات والفوحان، ودرجة تشابه لكل بديل. مصنّف في عشر عائلات عطرية، وبحث وفلترة فورية.

ملف واحد (`perfumes.html`) بلا خادم ولا خطوة بناء ولا أي اعتماد خارجي — افتحه في المتصفح فيعمل، ودون اتصال بعد التحميل الأول للخطوط.

## ✨ المزايا

- عطور مُقيَّمة، لكلٍّ منها بديل مُدروس (اسم + دار + نوتات).
- عشر عائلات عطرية ملوّنة، وقوارير **SVG مولّدة برمجياً** بلا صور ولا أصول.
- **بحث فوري** يطبّع الحروف العربية (التشكيل، الألف، ة/ه، ى/ي).
- فلترة بالعائلة والدار والمفضّلة وزر «الشراء الأعمى»، وترتيب بعدة معايير.
- **درجة تشابه** لكل بديل كشارة ملوّنة (توأم موثق / تطابق قوي / قريب / بروح مشابهة).
- حفظ الحالة في رابط الصفحة، وبيانات منظمة JSON-LD لمحركات البحث.
- واجهة **RTL** بترميز **UTF-8** وأرقام عربية-هندية، مع دعم `prefers-reduced-motion`.

## 🚀 التشغيل

```bash
open perfumes.html        # macOS
xdg-open perfumes.html    # لينكس
start perfumes.html       # ويندوز
```

أو انشره على أي استضافة ثابتة (GitHub Pages / Netlify / Cloudflare Pages) برفع `perfumes.html` فقط.

> الخطوط (`Aref Ruqaa`, `Tajawal`) تُجلب من Google Fonts؛ وباقي العمل يعمل دون اتصال.

التطبيق ملف واحد بلا اعتمادات. لإضافة عطر أو عائلة أو تعديل السلوك، راجع **[AGENTS.md](./AGENTS.md)** للقواعد التقنية ونموذج البيانات وخريطة الكود، ثم افتح Pull Request.
