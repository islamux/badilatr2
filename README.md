# بديل عطر ٢ · أفضل العطور الرجالية وبدائلها

> دليل تفاعلي يضم نخبة العطور الرجالية الأعلى تقييماً، إلى جانب **البديل العربي/الاقتصادي** الموثوق لكل قارورة — مع النوتات العطرية، نسب الثبات والفوحان، ودرجة تشابه لكل بديل. مصنّف في إحدى عشرة عائلة عطرية، وبحث وفلترة فورية، واختبار «بصمتك العطرية».

تطبيق **Next.js 16 + TypeScript + Tailwind CSS 4** بتصدير ثابت بالكامل (`output: 'export'`) — مساران: `/` (الفهرس) و `/quiz/` (الاختبار). الملف `perfumes.html` في جذر المستودع هو النسخة القديمة أحادية الملف، محفوظة كمرجع للتوافق فقط.

## ✨ المزايا

- **٥٦٩ عطراً مُقيَّماً**، لكلٍّ منها بديل مُدروس (اسم + دار + نوتات) ودرجة تشابه (توأم موثق / تطابق قوي / قريب / بروح مشابهة).
- إحدى عشرة عائلة عطرية ملوّنة، وقوارير **SVG مولّدة برمجياً** بلا صور.
- **بحث فوري** يطبّع الحروف العربية (التشكيل، الألف، ة/ه، ى/ي) ويدعم العربية واللاتينية.
- فلترة بالعائلة والدار والنوتة والمناسبة والمفضّلة وزر «الشراء الأعمى»، وترتيب بستة معايير.
- **وسوم مناسبات** لكل عطر (مكتب/صيف/سهرة/موعد/شتاء/مناسبات/يومي).
- **موسوعة النوتات**: ٤٩ نوتة في ١٢ مجموعة مع الوصف — والنقر على أي نوتة يفلتر الفهرس.
- **اختبار بصمتك العطرية**: ٦ أسئلة تُنتج ملفاً عطرياً وأفضل ٥ توصيات مع الأسباب.
- حفظ الحالة في رابط الصفحة (`#cat=…&q=…`) والمفضّلة في المتصفح، وبيانات JSON-LD لمحركات البحث.
- واجهة **RTL** بترميز **UTF-8** وأرقام عربية-هندية، مع دعم `prefers-reduced-motion`.

## 🚀 التشغيل

```bash
pnpm install    # تثبيت الاعتمادات (pnpm حصراً)
pnpm dev        # التطوير على http://localhost:3000
pnpm build      # بناء + تصدير ثابت إلى out/
npx serve out -l 3001   # معاينة النسخة الثابتة
```

## 📦 النشر

الإنتاج على **Hostinger**: ارفع محتويات `out/` إلى `public_html` بعد `pnpm build`. يعمل أيضاً على أي استضافة ثابتة (Vercel / Netlify / GitHub Pages) دون تهيئة إضافية.

> الخطوط (`Aref Ruqaa`, `Tajawal`) محلية في `public/fonts/` مع بديل Google Fonts.

## 🤝 المساهمة
