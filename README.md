# بديل عطر ٢ · أفضل العطور الرجالية وبدائلها

> دليل تفاعلي واحد يضم نخبة **العطور الرجالية** من أعلى التقييمات العالمية، إلى جانب **البديل العربي/الاقتصادي** الموثوق لكل قارورة — مع النوتات العطرية، نسب الثبات والفوحان، وحكم نهائي للشراء الأعمى. مصنّف في **عشر عائلات عطرية** وبحث وفلترة فورية.

ملف واحد (`perfumes.html`) لا يحتاج خادماً ولا خطوة بناء ولا أي اعتماد خارجي — افتحه في المتصفح فقط، ويعمل دون إنترنت بعد التحميل الأول للخطوط.

## ✨ المزايا

- **عطور مُقيَّمة**، لكلٍّ منها بديل مُدروس (اسم + دار + نوتات).
- **عشر عائلات عطرية** ملوّنة: خشبية، شرقية عنبرية، حمضية، أروماتيك، مائية، جلدية وتبغ، حارة، زهرية رجالية، جورماند، فوجير.
- **قوارير SVG مُولَّدة برمجياً** بخمسة أشكال وألوان لكل عائلة — لا صور، لا أصول، حجم صغير.
- **بحث فوري** مع تطبيع الحروف العربية (التشكيل، ألف/إ/آ، ة/ه، ى/ي، المدّة).
- **فلترة** بالعائلة + فلتر **الدار المنتجة** + زر «بدائل آمنة للشراء الأعمى فقط» + **المفضّلة**.
- **ترتيب**: الافتراضي / الأعلى تقييماً / الأطول ثباتاً / الأقوى فوحاناً / السعر / أبجدياً.
- **درجة تشابه كل بديل** كشارة ملوّنة على البطاقة (🎯 توأم موثق / ≈ تطابق قوي / ◐ قريب / 🌫 بروح مشابهة) — تُحدَّث تلقائياً مع الفرز والفلترة.
- **حفظ الحالة في رابط الصفحة** (`#cat=...&q=...&blind=1&sort=...&fav=1&brand=...`) — مشاركة نتيجة بحث محدّدة.
- **مفضّلة محفوظة** في المتصفح (`localStorage`).
- **بيانات منظمة JSON-LD** (`ItemList` من `Product`) لمحركات البحث.
- ظهور تدريجي عند التمرير، شريط تقدّم، زر العودة للأعلى، ودعم `prefers-reduced-motion`.
- واجهة **RTL** بترميز **UTF-8** وأرقام عربية-هندية (٠١٢٣…).

## 🧪 نموذج البيانات

كل عطر يُنشأ عبر الدالة المساعدة `D(...)` بهذا الترتيب:

```
D(العائلة,
  الاسم_عربي, الاسم_إنجليزي, الدار_إنجليزي, الدار_عربي,
  [نوتات_الأصلي],
  البديل_عربي, دار_البديل_إنجليزي, دار_البديل_عربي,
  [نوتات_البديل],
  ثبات_الأصلي٪, فوحان_الأصلي٪,
  ثبات_البديل٪, فوحان_البديل٪,
  أمان_الشراء_الأعمى_للأصلي (true|false),
  أمان_الشراء_الأعمى_للبديل (true|false),
  التقييم (4.x), فئة_السعر ('$'|'$$'|'$$$'))
```

والعائلات معرّفة في الكائن `CATS` بالمفتاح → `{ n:الاسم, d:الوصف, c:اللون, c2:اللون_الداكن }`.

## 🛠️ التخصيص السريع

- **إضافة عطر:** أضف سطر `D(...)` داخل مصفوفة `data` (`perfumes.html:239`) ضمن دفعة عائلته.
- **إضافة عائلة:** أضف مفتاحاً إلى `CATS` (`perfumes.html:225`) بلون مميّز.
- **درجة تشابه بديل:** أضف/عدّل إدخالاً في قاموس `SIM` (`perfumes.html:986`) — المفتاح اسم البديل والقيمة ٠–١٠٠.
- **الألوان العامة:** متغيرات `:root` في الأعلى (`--gold`, `--ink`, `--bg` …).
- **التشفير:** احفظ الملف دائماً بترميز **UTF-8** وإلا تتعطّل العربية.
